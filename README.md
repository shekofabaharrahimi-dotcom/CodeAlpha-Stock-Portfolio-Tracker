# Stock Portfolio Tracker

## Description

Stock Portfolio Tracker is a Python console application that calculates the total value of a user's stock investments.

The program uses a predefined collection of stock prices and allows the user to build a portfolio by entering stock names and share quantities.

## Features

- Add stocks to a portfolio
- Enter the number of shares
- Use predefined stock prices
- View the current portfolio
- Calculate total investment value
- Save the final portfolio to a text file
- Handle invalid stock names and quantities

## Technologies Used

- Python 3

## Python Concepts

- Dictionaries
- While Loops
- Conditional Statements
- Lists
- String Handling
- User Input and Output
- Arithmetic Operations
- File Handling

## Available Stocks

- NVIDIA
- Meta
- Netflix
- Intel
- Coca-Cola

## How to Run

Open a terminal in the project folder and run:

```bash
py portfolio_tracker.py
```

## Output File

After finishing the portfolio, the program creates:

```text
portfolio_report.txt
```

The file contains the selected stocks, quantities, individual values, and total investment.
